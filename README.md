# DSH Duo Model（预览版）

为 DeepSeek Harness 提供「思考者 / 工作者」双模型选择条，目标是由较强模型规划和复核，由低成本模型执行任务。

## 当前状态

这是开发预览源码，不是已完成端到端验收的稳定版本。

- 界面设计包含两个模型选择格、角色互换和启用开关。
- 本版修正模型选择方法：使用 directory.select，而不是只读 store.select。
- 模型目录加载已移至组件 effect；每个会话复用状态 store，避免在插槽注入期间重复加载。
- 选择任一角色不会自动开启分工，两个角色选好后再开启。
- HTTP 接口保留宿主身份认证；401 不会因为请求来自本机而被放行。宿主认证服务缺失时返回 503。
- 已验证 JavaScript 语法及一次普通子代理委派测试；测试生成的 Python 函数通过三个测试。
- 尚未验证：新会话双格实际显示、真实点击切换、指定工作者模型被正确调用、跨会话持久化及重启恢复。普通子代理调用成功不等于双模型路由验收通过。

## 兼容性与安装

开发时宿主版本为 0.2.1-rc.3；manifest 的 peerDependencies 声明该版本。其他版本未验证。依赖由包管理器解析，不包含本机绝对路径或 node_modules。

请使用 Harness 插件管理器安装本地目录。本包不附带自动修改用户 profile 的脚本。安装前保留现有配置，使用独立测试 profile 验证；不要同时手工插入同名加载项与安装 bundle，以免重复注册。

## 使用与验收

1. 在输入框下方查找「双模型」条。
2. 选择思考者和工作者；确认思考者与原生模型选择器同步。
3. 开启分工，发送一个小型委派任务。
4. 核对子任务真实模型路由；仅有模型文字自述不算验证。

## 文件

- index.js：宿主服务、委派工具和提示上下文。
- client.js：React 界面和模型目录连接。
- route.js：状态读取与保存接口。
- cordis.patch.yml：插件加载声明。
- locale/ 与 icon.svg：显示资源。

## 已知限制

当前仍使用宿主内部 modelDirectories 服务，升级兼容性需要复核。会话白名单与内存状态的生命周期也需要进一步验证。本次发布未测量节省费用或加速比例。
